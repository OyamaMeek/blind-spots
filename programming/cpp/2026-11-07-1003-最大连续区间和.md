# 1003 最大连续区间和 · 复习清单

## 已提出的疑问

| 知识点 | 当时的疑问 | 复习要点 |
| --- | --- | --- |
| 时间复杂度 | 为什么会超时，如何修改？ | 三层循环反复计算区间和，时间复杂度为 $O(n^3)$。一次遍历可以降到 $O(n)$。 |
| `sum` 的含义 | `sum` 是干什么的？ | `sum` 表示以当前元素结尾的最大连续区间和，`maxSum` 保存截至当前位置遇到的最大区间和。 |
| 算法思路 | 为什么这样遍历就能找到答案？ | 以当前元素结尾的非空区间，要么只含当前元素，要么由前一个位置结尾的区间延长而来。取两者的最大和作为 `sum`，再用它更新 `maxSum`。 |

## 待自测

1. **为什么累计和为负数时可以舍弃？** 把一段和为负的前缀接到后面的区间上，只会使区间和更小，所以可以从当前元素重新开始。
2. **为什么遇到负数不一定重新开始？** 判断的是加上当前元素之前的 `sum`。例如 `3, -1, 4` 的最大和来自整个区间。
3. **`tempStart` 和 `start` 为什么分开？** `tempStart` 记录当前候选区间的起点，`start` 记录目前最佳区间的起点。候选起点变化时，只有发现更大的区间和才更新最佳区间。
4. **为什么初始化为 `a[1]`？** 使用从 1 开始的下标时，先令 `sum` 和 `maxSum` 等于第一个元素，再从第二个元素开始遍历。题目要求区间非空，全负数时答案是最大的负数。
5. **为什么条件是 `< 0` 和 `> maxSum`？** 仅在前一步的 `sum < 0` 时重新开始，能在 `sum == 0` 时保留更早的候选起点。仅在 `sum > maxSum` 时更新答案，能保留首次记录的最大和区间。并列时的输出要求以原题题面为准。
