# P5729【深基5.例7】工艺品制作

## 题目

一块大小为 $w\times x\times h$ 的玻璃长方体由单位小方块组成。做 $q$ 次切割，每次给出两个对角点 $(x_1,y_1,z_1)$ 和 $(x_2,y_2,z_2)$，切除所有满足以下条件的小方块 $(i,j,k)$：

$$
x_1\le i\le x_2,\qquad y_1\le j\le y_2,\qquad z_1\le k\le z_2.
$$

第一行输入 $w,x,h$，第二行输入 $q$，接下来 $q$ 行各输入六个整数 $x_1,y_1,z_1,x_2,y_2,z_2$。其中 $1\le w,x,h\le 20$，$1\le q\le 100$，且 $1\le x_1\le x_2\le w$、$1\le y_1\le y_2\le x$、$1\le z_1\le z_2\le h$。输出所有切割完成后剩余的小方块数。[洛谷原题](https://www.luogu.com.cn/problem/P5729)

## 为什么逐次减体积会算错

两个切割区域可能重叠，同一个小方块只能被移除一次。以 $3\times 1\times 1$ 的玻璃块为例，第一次切第 1、2 格，第二次切第 2、3 格。直接相减会得到 $3-2-2=-1$，因为第 2 格被扣了两次。三格都被切掉，正确答案是 $0$。

## 三维数组模拟

1. 用 `a[i][j][k]` 记录坐标 $(i,j,k)$ 的状态。初始全为 `0`，表示仍然存在，`1` 表示已切除。
2. 每次用三层循环遍历三个闭区间，把覆盖到的元素设为 `1`。同一位置被覆盖多次时，状态始终为 `1`。
3. 处理完全部切割后，再遍历整个玻璃块，数出状态仍为 `0` 的小方块。

处理完任意次数的切割后，某个格子为 `1` 当且仅当它至少被一次切割覆盖，所以最后为 `0` 的格子恰好是剩余部分。题目最多有 $8000$ 个小方块，切割循环至多执行 $800000$ 次，最后另扫描至多 $8000$ 格。最坏时间复杂度为 $O((q+1)wxh)$，代码使用固定的 $25\times25\times25$ 个 `int` 存储状态。

## C++ 参考代码

```cpp
#include <iostream>
using namespace std;

int a[25][25][25];

int main() {
    int w, x, h, q;
    cin >> w >> x >> h >> q;

    while (q--) {
        int x1, y1, z1, x2, y2, z2;
        cin >> x1 >> y1 >> z1 >> x2 >> y2 >> z2;

        for (int i = x1; i <= x2; i++) {
            for (int j = y1; j <= y2; j++) {
                for (int k = z1; k <= z2; k++) {
                    a[i][j][k] = 1;
                }
            }
        }
    }

    int ans = 0;
    for (int i = 1; i <= w; i++) {
        for (int j = 1; j <= x; j++) {
            for (int k = 1; k <= h; k++) {
                if (a[i][j][k] == 0) {
                    ans++;
                }
            }
        }
    }

    cout << ans << endl;
    return 0;
}
```

## 易错点

- **初始化**。全局数组会自动清零。把数组移入 `main` 时，可用 `int a[25][25][25] = {0};` 显式清零。
- **数组长度**。坐标从 `1` 开始，最大坐标是 `20`。要访问下标 `20`，每一维的长度至少为 `21`。
- **循环顺序和端点**。统计时 `i`、`j`、`k` 分别对应 `w`、`x`、`h`。切割区域包含两个端点，所以用 `<=`，两端相等时也要处理那一格。

## 可迁移的教训

见到多次覆盖且区域可能重叠 → 检查同一元素是否只能计数一次。如果坐标范围小，可以逐格标记状态，再统一统计。
